# Constant-Cycle Hardware Private Circuits

This repository contains the artifacts accompanying the papers on the original [CCHPC1](CCHPC1/) [\[LMDM25\]](https://eprint.iacr.org/2025/1331) and its follow-up [CCHPC1.1](CCHPC1_1/) [\[LWM26\]](https://doi.org/10.46586/tches.v2026.i4.208-236) with architectural improvements. See the respective subfolder READMEs for details.

## References

\[LMDM25\] Daniel Lammers, Nicolai Müller, Siemen Dhooghe, and Amir Moradi. [Constant-Cycle Hardware Private Circuits](https://eprint.iacr.org/2025/1331). *IACR Transactions on Cryptographic Hardware and Embedded Systems*, 2025(4).

\[LWM26\] Daniel Lammers, Lukas Weber, and Amir Moradi. [Area Efficiency in Constant-Cycle Schemes – CCHPC1.1 and Architectural Overhead Reduction Applied to AES](https://doi.org/10.46586/tches.v2026.i4.208-236). *IACR Transactions on Cryptographic Hardware and Embedded Systems*, 2026(4).
